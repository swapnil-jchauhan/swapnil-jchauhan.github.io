Jarvis Assistant

Jarvis Assistant is a personal, single-user voice assistant that runs on its owner's own Windows PC. It uses the owner's Google Calendar, Gmail, Google Drive and YouTube accounts only to carry out the owner's own spoken requests, such as adding a calendar event or finding a file.

It is not offered to the public. There is no sign-up and no server run by the developer.
